# Blue + Gold Edition

Variante visual creada a partir de `amp-salud-lc-animaciones`.

Paleta principal:
- Azul institucional: `#0B2D5C`
- Azul secundario: `#123E78`
- Azul de acción: `#0B4D9B` / `#2563B9`
- Dorado de marca: `#B78A3A`
- Dorado claro: `#D7B66F`
- Fondo azul muy claro: `#F4F8FD`
- Blanco: `#FFFFFF`
- Texto: `#17243A`

El dorado se usa como acento y no como color dominante. Los CTA principales permanecen azules para conservar claridad y una estética institucional moderna.
